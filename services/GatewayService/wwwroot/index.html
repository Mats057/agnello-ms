Sobre este ambiente

escopo acadêmico
  • ASP.NET Core/.NET 10 com OpenAPI nativo e Scalar.
  • Gateway YARP como único ponto de acesso às APIs.
  • JWT para autenticação entre cliente e serviços protegidos.
  • REST síncrono entre Pedidos e Estoque; RabbitMQ para eventos.
  • Dados mantidos em memória para simplificar a demonstração.
  • Docker Compose fornece rede interna, DNS por nome de serviço e isolamento de portas.
